Image-only flashcards for MedQ Daily.

Place image files in subject folders, for example assets/flashcards/anatomy/heart-001.webp.
Then add a record to data/flashcards.js: { id: "anatomy-heart-001", subject: "Anatomy", topic: "Heart", img: "assets/flashcards/anatomy/heart-001.webp" }.
No sample cards are included because the actual card images must be supplied by the site owner.
